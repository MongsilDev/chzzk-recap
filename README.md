# chzzk-recap

치지직 연말 리캡 통계를 보여주는 웹앱. 치지직 연말결산 API JSON을 붙여넣으면 한 해 가장 많이 본 채널과 시청 통계를 요약 카드·순위·차트로 시각화한다.

## 주요 기능

- 연말결산 JSON 붙여넣기 → 스키마 검증 후 리캡 렌더
- 요약 카드(총 시청 시간·총 통나무 파워·주 시청 시간대)
- 가장 많이 본 채널 순위(시청 시간·통나무 파워·클립 통계)
- 채널별 시청 비중 파이 차트

## 동작 방식

서버 없이 브라우저에서만 동작하며, 앱이 직접 치지직 API를 호출하지 않는다. 사용자가 붙여넣은 `year-end-users` 응답을 Zod로 검증·집계해 Chart.js로 렌더한다.

## 기술 스택

Next.js 16, React 19, TypeScript, Tailwind + shadcn/ui, Chart.js, Zod. Vercel 배포.

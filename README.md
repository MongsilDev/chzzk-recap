# chzzk-recap

치지직 연말결산 JSON을 붙여넣으면 한 해 시청 통계를 요약 카드와 순위, 차트로 보여주는 웹앱. 붙여넣은 데이터는 서버로 전송되지 않고 브라우저 안에서만 처리되며, 앱이 치지직 API를 직접 호출하지 않는다.

## 기능

- 연말결산 JSON 붙여넣기와 스키마 검증
- 요약 카드: 총 시청 시간, 총 통나무 파워, 주 시청 시간
- 가장 많이 본 채널 순위: 시청 시간, 통나무 파워, 클립 제작 수, 클립 조회 수, 채널 바로가기
- 채널별 시청 시간 비중 파이 차트

## 동작 방식

사용자가 치지직 연말결산 API `https://api.chzzk.naver.com/service/v1/year-end-users?year=2025` 응답을 복사해 붙여넣으면 Zod 스키마로 검증한다. 검증에 통과하면 요약 카드와 순위를 보여주고, 채널별 시청 시간 비중은 Chart.js 파이 차트로 그린다. URL의 연도 값을 바꾸면 다른 해의 리캡을 볼 수 있다.

## 실행

Node 20 이상이 필요하다.

```bash
npm install
npm run dev
```

프로덕션 빌드:

```bash
npm run build
npm start
```

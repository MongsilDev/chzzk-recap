# chzzk-recap

치지직 연말결산 JSON을 붙여넣으면 한 해 시청 통계를 요약 카드와 순위, 차트로 보여 주는 웹앱입니다.\
붙여넣은 데이터는 서버로 보내지 않고 브라우저 안에서만 처리하며, 앱이 치지직 API를 직접 호출하지 않습니다.

## 기능

- 연말결산 JSON 붙여넣기와 스키마 검증
- 요약 카드: 총 시청 시간, 총 통나무 파워, 주 시청 시간
- 가장 많이 본 채널 순위: 시청 시간, 통나무 파워, 클립 제작 수, 클립 조회 수.\
  채널 이름을 누르면 치지직 채널로 이동
- 채널별 시청 시간 비중 파이 차트

## 동작 방식

치지직 연말결산 API `https://api.chzzk.naver.com/service/v1/year-end-users?year=2025` 응답을 복사해 붙여넣으면 Zod 스키마로 검증합니다.\
검증을 통과하면 요약 카드와 순위를 보여 주고, 채널별 시청 시간 비중은 Chart.js 파이 차트로 그립니다.\
화면의 `2025 JSON`, `2024 JSON` 버튼이 해당 연도의 API 주소를 엽니다.\
로그인하지 않은 상태의 응답은 빈 목록이라, 이 경우 치지직에 로그인하라고 안내합니다.

## 실행

Node 20 이상이 필요합니다.

```bash
npm install
npm run dev
```

프로덕션 빌드:

```bash
npm run build
npm start
```
